# ДЗ 34.1. Webpack в дії

Окремий Webpack-проєкт для практики конфігурації збірки та управління активами.

## Реалізовано

- хешування імен файлів через `[contenthash]` для JavaScript, зображень і шрифтів;
- локальний шрифт `Roboto Mono`, який підключається через `@font-face`;
- робота із зображенням, яке імпортується в JavaScript і проходить через asset modules;
- CSS винесено в окремі файли та підключено через entry point;
- зовнішні бібліотеки `normalize.css` і `lodash-es` винесено в оптимізований vendor chunk через `splitChunks`;
- сторінка має footer-кнопку повернення на головний індекс усіх домашніх завдань.

## Команди

```bash
npm install
npm run build
npm run dev
```

Після `npm run build` готова сторінка буде в папці `dist`.
